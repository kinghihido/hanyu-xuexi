# 汉语言学习 · 古代汉语 / 现代汉语

北京大学《古代汉语》《现代汉语》课堂讲义整理网站。

## 站点结构

- **古汉语模块**（`gudai/`）：六讲课件整理，繁体原文。课件自带「字詞＋譯」处逐句照录；课件未加注的文言文，补〔編者補注〕关键词批注与白话今译。
  1. 绪论
  2. 精卫填海
  3. 古书的注解
  4. 郑伯克段于鄢
  5. 古汉语常用工具书
  6. 齐桓公伐楚
- **现代汉语模块**（`xiandai/`）：两篇讲义原文收录。
  1. 现代汉语绪论：一门共同语言是怎样走到我们身边的
  2. 声音如何成为语言：语音概说

## 技术说明

- 纯静态站点：HTML + 单份共享 CSS，无外部依赖、无构建步骤。
- 视觉：古汉语模块宣纸底色与朱砂强调；现代汉语模块青黛配色。
- 依赖 GitHub Pages 直接部署 `main` 分支根目录。

## 本地预览

直接双击 `index.html` 即可在浏览器打开。

## 来源

古汉语内容整理自北京大学《古代汉语》课程课件（PDF）；现代汉语内容为用户提供的课堂讲义文字。整理仅供学习交流使用。
